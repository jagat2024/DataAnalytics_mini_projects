
# 🚢 Titanic Survival Prediction

## 📌 Project Overview

This project focuses on predicting whether a passenger survived the Titanic disaster using Machine Learning classification algorithms.

The project involves data preprocessing, exploratory data analysis, model training, and performance evaluation using multiple classification algorithms.

## 🎯 Objectives

- Understand and preprocess the Titanic dataset.
- Handle missing values and categorical data.
- Train multiple Machine Learning classification models.
- Evaluate and compare model performance.
- Understand different classification evaluation metrics.

## 📊 Dataset Information

The dataset contains passenger information such as:

| Feature | Description |
|---|---|
| Pclass | Passenger class |
| Sex | Passenger gender |
| Age | Passenger age |
| SibSp | Siblings/spouses aboard |
| Fare | Ticket fare |
| Embarked | Port of embarkation |
| Alone | Whether passenger travelled alone |
| Survived | Target variable (0 or 1) |

**Target Variable:**
- `0` - Did not survive
- `1` - Survived

Dataset is loaded using Seaborn.
