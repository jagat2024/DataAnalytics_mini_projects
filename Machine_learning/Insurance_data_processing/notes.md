# Insurance Data Preprocessing

This project focuses on cleaning and preparing an insurance dataset for further data analysis and machine learning.

## What I Did

- Loaded and explored the dataset using Pandas.
- Checked for missing values and handled them.
- Cleaned and prepared the data for analysis.
- Worked with categorical columns such as `sex`, `smoker`, and `region`.
- Prepared the dataset for future machine learning tasks.

## Tools Used

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Goal

To understand how raw insurance data can be cleaned and transformed into a usable format for machine learning.
